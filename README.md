# Welcome to Lengors Labs &middot; [![GitHub license](https://img.shields.io/github/license/lengors-labs/.github?color=blue)](https://github.com/lengors-labs/.github/blob/main/LICENSE)

Welcome to the **Lengors Labs** organization's shared configuration repository.

This repository contains the default community health files and GitHub configuration that GitHub applies across all repositories in the [`lengors-labs`](https://github.com/lengors-labs) organization, such as issue and pull request templates, and other shared settings.

## What's in here

- `CODEOWNERS` — default code owners for the organization.
- `FUNDING.yml` — sponsorship configuration.
- `ISSUE_TEMPLATE/` — issue forms and issue configuration.
- `PULL_REQUEST_TEMPLATE.md` — default pull request template.
- `CODE_OF_CONDUCT.md` — our code of conduct.
- `CONTRIBUTING.md` — contribution guidelines.
- `SECURITY.md` — security policy.
- `SUPPORT.md` — support resources.

## How it works

Any repository in the organization that does not provide its own version of one of these files automatically inherits the copy in this repository. This lets us keep our community health files and GitHub configuration consistent across the organization, while still allowing individual repositories to override them when needed.

For more details, see GitHub's documentation on [creating a default community health file](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
